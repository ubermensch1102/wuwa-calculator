# 명조 고정 사이클 총딜 계산기 Beta 1.0

실제 JavaScript 계산 엔진이 연결된 첫 실행 버전입니다.

- 개별 캐릭터 고정 사이클 총피해 및 공격별 피해
- 3인 팀 A/B 비교
- 캐릭터별 피해 변화
- 재화 효율 자동 순위 (캐릭터 82뽑, 무기 55뽑 고정)
- 표준 부옵 / 최종 스탯 직접 입력
- S/R 및 스킬 레벨 입력
- 검증 픽스처
- 미보유 15캐릭터 제외

현재 정확도 검증 대상 데이터는 에이메스·데니아·수수입니다. Lv1–9 스킬 계수는 아직 공통 근사 스케일이며, Lv10이 검증 기준입니다.

## iPhone
ChatGPT/Files의 HTML 미리보기(Quick Look)는 JavaScript를 실행하지 않을 수 있습니다. 이 파일 자체는 일반 웹 브라우저에서 실행되는 정적 웹앱입니다. iPhone에서 확실하게 쓰려면 정적 호스팅(GitHub Pages/Cloudflare Pages 등)에 올려 Safari로 접속해야 합니다.
